How to install dbt Docker for databricks

In this article I will explain you how did I create a docker image for databricks. As of Aug 2023, I have not found a recipe to build dbt-databricks image.

Softwares Required to run Docker

If all you want to run is Docker containers, then just the Docker engine and its supporting packages which can be found in the ‘installation’ section in the Docker documentation will suffice:

Install Docker Engine

Once installed start the Docker Desktop

% docker --version
Docker version 24.0.5, build ced0996

Docker Image build for databricks

As of Aug 2023 when I am writing this article, I have not found a dockerised dbt for databricks. I choose to use the slim python image to build the docker image to keep the image size small.

  1. Dockerfile to build the image for dbt-databricks

In the docker file you can comment the below line if you have certs installed,

# Add trusted hosts for pip install
RUN pip config set global.trusted-host \
 "pypi.org files.pythonhosted.org pypi.python.org"

else if you get SSL_CERT error you need to add python repository end points to trusted hosts

##
# base image (abstract)
##
FROM python:3.11-slim-bullseye

LABEL maintainer="emp0-data-whisperer"

# Env vars
ENV PYTHONIOENCODING=utf-8
ENV LANG=C.UTF-8

WORKDIR /usr/src/dbt

# Add trusted hosts for pip install
#RUN pip config set global.trusted-host \
#    "pypi.org files.pythonhosted.org pypi.python.org"

# Install OS dependencies
RUN apt-get update && apt-get install -qq -y --no-install-recommends \
    #ca-certificates \
    #git gcc build-essential libpq-dev ca-certificates --fix-missing --no-install-recommends \ 
    && update-ca-certificates -v \
    && rm -rf /var/lib/apt/lists/* \
    && apt-get clean

# Make sure we are using latest pip
RUN pip install --upgrade pip

# Copy requirements.txt
COPY requirements.txt requirements.txt

# Install dependencies
RUN pip install -r requirements.txt \
    && pip cache purge

CMD dbt deps  && sleep infinity

2. Created enviroment file (.env) to stored all the variables.

BUILD_VERSION is the version of the databricks which is also the version of the docker image that will be built.
DBT_PROJECT should hold the path to your dbt project.
DBT_PROFILES should the path to your profiles.yml
DBT_DOCS_PORT is the port number to serve docs
DOCKER_IMAGE_NAME is the name of the docker image that will be built
DOCKER_CONTAINER_NAME is the name of the container
BUILD_VERSION=1.8.6

DBT_PROJECT=/Users/alwyndsouza/repos/dbt_project_test
DBT_PROFILES=~/.dbt/profiles.yml
DBT_DOCS_PORT=8080

DOCKER_IMAGE_NAME=docker-dbt-databricks
DOCKER_CONTAINER_NAME=dbt

3. Build the docker compose file

docker-compose.yml

version: '3.8'

services:

  dbt:
    build:
      context: .
      dockerfile: Dockerfile
    image: ${DOCKER_IMAGE_NAME}:${BUILD_VERSION}
    container_name: ${DOCKER_CONTAINER_NAME}
    command: [ "/bin/bash" ]
    ports:
      - "${DBT_DOCS_PORT}:8080"
    stdin_open: true
    env_file: .env
    volumes:
      - ${DBT_PROJECT}:/usr/src/dbt
      - ${DBT_PROFILES}:/root/.dbt/profiles.yml
    tty: true
    networks:
      - default

4. Start and Stop the docker stack

Have create scripts to keep it simple. You can use the below scripts to start and stop the docker stacks.

start_docker_stack.sh

#!/bin/sh
docker-compose up --build -d
docker image prune --all --force

You can run start_docker_stack.sh to build and run the container

sh start_docker_stack.sh

stop_docker_stack.sh

#!/bin/sh
docker-compose down

In order to stop the running container, run the below command

sh stop_docker_stack.sh

5. Test the Setup

After running start_docker_stack.sh, you should see the image has been created and container running.

you can test the setup by running the below command.

docker exec -it dbt dbt --version

7. Creating alias for docker command

I prefer using alias to the lengthy docker command to keep it simple.

On Mac , you can add the below line to .zshrc file

alias dbt-databricks="docker exec -it dbt dbt "

once added execute,

source ~./zshrc

and run the docker container as show below.
