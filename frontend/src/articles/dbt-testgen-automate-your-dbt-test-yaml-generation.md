<p>dbt-testgen is a powerful dbt package designed to automatically generate dbt test YAML files based on real data. Inspired by dbt-codegen, this tool simplifies the process of creating comprehensive tests for your data models.</p><h3>Installation</h3><p>To get started with dbt-testgen, ensure you have dbt version 1.2.x or higher. Add the following to your <code>packages.yml</code> file:</p><pre spellcheck="false">packages:<br /> - package: kgmcquate/testgen<br /> version: 1.0.3</pre><h3>Supported Test Types</h3><p>dbt-testgen can generate a variety of tests using built-in tests, dbt_utils, and dbt-expectations, including:</p><ul><li>Uniqueness</li><li>Not Null</li><li>String Length</li><li>Range</li><li>Accepted Values</li><li>Recency</li></ul><h3>Usage</h3><p>The dbt configuration YAML is generated by a Jinja macro called <code>get_test_suggestions</code>. You can run it with the following command:</p><p><em>“from dbt 1.9, tests is defined as data_tests. So update the tests in generated yml file to data_tests”</em></p><pre spellcheck="false">dbt compile -q --inline &quot;{{ testgen.get_test_suggestions(ref(&#x27;stg_system__account_manager&#x27;)) }}&quot;</pre><p>Here’s an example output:</p><pre spellcheck="false">models:<br /> - name: stg_system__account_manager<br /> columns:<br /> - name: account_id<br /> tests:<br /> - unique<br /> - not_null<br /> - name: account_manager_flag<br /> tests:<br /> - accepted_values:<br /> values:<br /> - &#x27;1&#x27;</pre><h3>Advanced Usage</h3><p>For more advanced configurations, you can set the following arguments:</p><h3>Example Command</h3><p>Here’s an example of running the command with advanced arguments:</p><pre spellcheck="false">dbt compile -q --inline &quot;{{ testgen.get_test_suggestions(ref(&#x27;stg_system__account_manager&#x27;), exclude_types=[&#x27;float&#x27;], tests=[&#x27;uniqueness&#x27;, &#x27;accepted_values&#x27;, &#x27;range&#x27;, &#x27;string_length&#x27;], limit=1000000000) }}&quot;</pre><p>This will generate the following output:</p><pre spellcheck="false">models:<br /> - name: stg_system__account_manager<br /> columns:<br /> - name: account_id<br /> tests:<br /> - unique<br /> - not_null<br /> - name: account_manager_flag<br /> tests:<br /> - accepted_values:<br /> values:<br /> - &#x27;1&#x27;</pre><p>With dbt-testgen, you can streamline your testing process and ensure your data models are thoroughly validated with minimal effort. Happy testing!</p><h3>References</h3><a href="https://github.com/kgmcquate/dbt-testgen" title="https://github.com/kgmcquate/dbt-testgen"><strong>GitHub - kgmcquate/dbt-testgen: Generate DBT tests based on sample data</strong><br><em>Generate DBT tests based on sample data.
