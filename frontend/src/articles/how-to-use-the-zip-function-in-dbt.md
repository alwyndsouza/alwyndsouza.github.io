<blockquote>dbt (data build tool) is a powerful tool for transforming data in your warehouse. One of the lesser-known but incredibly useful features in dbt is the <strong>zip</strong> function, which can be used within Jinja templates to combine multiple lists into a single iterable of tuples.</blockquote><h4>What is the zip Function?</h4><p>The zip function in dbt is a context method that allows you to combine multiple iterables (like lists) into a single iterator of tuples. Each tuple contains elements from the input iterables at the same position. This can be particularly useful when you need to iterate over multiple lists simultaneously in your dbt models.</p><h4>Basic Usage</h4><p>Let’s start with a simple example. Suppose you have two lists: one containing names and another containing corresponding ages. You can use the zip function to combine these lists into a single iterable of tuples.</p><pre spellcheck="false">{% set names = [&#x27;Alice&#x27;, &#x27;Bob&#x27;, &#x27;Charlie&#x27;] %}<br />{% set ages = [25, 30, 35] %}<br />{% set combined = zip(names, ages) | list %}<br /><br />{% for name, age in combined %}<br /> {{ name }} is {{ age }} years old.<br />{% endfor %}</pre><p>In this example, the zip function combines the names and ages lists into a list of tuples: <code>[(&#39;Alice&#39;, 25), (&#39;Bob&#39;, 30), (&#39;Charlie&#39;, 35)]</code>. The for loop then iterates over these tuples, allowing you to access both the name and age in each iteration.</p><h4>Dynamic Column Selection and Aggregation</h4><p>Suppose you have a list of metrics and corresponding tables, and you want to generate a SQL query that calculates the sum of each metric from its respective table. Here’s how you can use the zip function to achieve this:</p><pre spellcheck="false">{% set metrics = [&#x27;revenue&#x27;, &#x27;profit&#x27;, &#x27;expenses&#x27;] %}<br />{% set tables = [&#x27;sales&#x27;, &#x27;finance&#x27;, &#x27;costs&#x27;] %}<br />{% set combined = zip(metrics, tables) | list %}<br /><br />WITH aggregated_data AS (<br />{% for metric, table in combined %}<br /> SELECT<br /> &#x27;{{ metric }}&#x27; AS metric_name,<br /> SUM({{ metric }}) AS total_value<br /> FROM {{ table }}<br /> {% if not loop.last %} UNION ALL {% endif %}<br />{% endfor %}<br />)<br /><br />SELECT<br /> metric_name,<br /> total_value<br />FROM aggregated_data<br />ORDER BY metric_name;</pre><blockquote><strong>Generated SQL will be :</strong></blockquote><pre spellcheck="false">WITH aggregated_data AS (<br /> SELECT<br /> &#x27;revenue&#x27; AS metric_name,<br /> SUM(revenue) AS total_value<br /> FROM sales<br /> UNION ALL<br /> SELECT<br /> &#x27;profit&#x27; AS metric_name,<br /> SUM(profit) AS total_value<br /> FROM finance<br /> UNION ALL<br /> SELECT<br /> &#x27;expenses&#x27; AS metric_name,<br /> SUM(expenses) AS total_value<br /> FROM costs<br />)<br /><br />SELECT<br /> metric_name,<br /> total_value<br />FROM aggregated_data<br />ORDER BY metric_name;</pre><p>This example demonstrates how the zip function can be used to dynamically generate SQL code for more complex data transformations in dbt models.</p><h3>References</h3><a href="https://docs.getdbt.com/reference/dbt-jinja-functions/zip" title="https://docs.getdbt.com/reference/dbt-jinja-functions/zip"><strong>About zip context method | dbt Developer Hub</strong><br><em>Use this context method to return an iterator of tuples.</em>docs.getdbt.com</a><a href="https://docs.getdbt.com/reference/dbt-jinja-functions/zip" style="background-image: url(https://cdn-images-1.medium.com/fit/c/160/160/0*YcVhM6Y2g31xsAe5);"></a><p><a href="https://github.com/dbt-labs/dbt-core/pull/5107" rel="nofollow noopener" target="_blank">https://github.com/dbt-labs/dbt-core/pull/5107</a></p>
